# Excel files in chatlocal
Read .xlsx attachments from the supplied extracted sheet rows. Content may be truncated. Create a real Excel file with action=document, format=xlsx, title, sheets=[{name,rows:[["Tên","Giá"],["Sản phẩm",100]]}]. Rows contain strings, finite numbers, booleans, null, or {formula:"SUM(B2:B5)",result:optional_number}. Strings starting with = remain literal; use formula objects for formulas.
Edit an existing XLSX using action=document, format=xlsx, title, attachment=current-chat attachment/artifact ID, cells=[{sheet:"Sheet1",cell:"B2",value:123}]. Existing sheets only, A1 addresses. Return the downloadable copy from the controller. Source is unchanged. ExcelJS reads/writes the workbook; advanced features unsupported by ExcelJS (e.g. some drawings) may not survive. Formulas are saved but not evaluated locally; only provide cached results when actually known. Legacy .xls, encrypted files, macros and guaranteed layout preservation are unsupported. Never claim success before the controller returns an artifact.
