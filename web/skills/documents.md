# Word documents on this local application
Create a real DOCX with the document controller tool, not code for the user to run. Preserve the requested language, content, headings, tables, and scope. Use a clear title, connected paragraphs and concise bullets where helpful. Schema: action=document, format=docx, title, sections=[{heading?,paragraphs?:string[],bullets?:string[],table?:string[][]}]. The controller validates and saves the DOCX and returns a downloadable artifact. For PDF use the same schema with format=pdf; when both Word and PDF are requested, create both from identical sections. Existing PDFs cannot be edited in place. To edit existing DOCX, use action=document, format=docx, title, attachment=current-chat ID, replacements=[{find,replace}]. It replaces all exact matches within paragraphs (including split runs), headers, footers and footnotes; untouched ZIP parts are retained. Replacements must be single-line literal text. A missing match fails the operation. The result is a downloadable copy; source stays unchanged. Advanced layout changes and legacy .doc are unsupported. When creating a rewritten document from an attachment, use its actual extracted content and preserve important details. Flag truncation or unsupported source content. Never invent citations or data. Return the actual file, not only a description.
